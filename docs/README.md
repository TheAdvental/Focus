# Документація «Фокуса»

«Фокус» — особиста система проти прокрастинації: план дня, таймер фокусу, нагадування, блокування відволікань на комп'ютері й телефоні, синхронізація через власний сервер.

| Документ | Для кого і про що |
|---|---|
| [Посібник користувача](user-guide.md) | Як користуватися додатком щодня: завдання, таймер, нагадування, блокування, статистика |
| [Встановлення і налаштування](installation.md) | Як поставити кожну частину: сервер, програму для ПК, розширення, Android, календар, Claude |
| [Як усе влаштовано](architecture.md) | Частини системи, модель даних, синхронізація, хто з ким і як спілкується |
| [Довідник з API](api.md) | Адреси сервера, інструменти для Claude, локальна адреса програми для ПК, мости до оболонок |
| [Вирішення проблем](troubleshooting.md) | Що робити, коли щось не блокується, не синхронізується чи не нагадує |

## Коротко про частини

| Частина | Що робить | Чи обов'язкова |
|---|---|---|
| Додаток (`index.html`) | Увесь інтерфейс: план, таймер, статистика, налаштування | Так |
| Програма для ПК | Те саме у вікні; закриває програми під час фокусу, нагадує з трею | Для блокування на ПК |
| Розширення для браузера | Блокує сайти під час фокусу | Для блокування сайтів |
| Додаток для Android | Той самий інтерфейс; блокує програми на телефоні, нагадує сповіщеннями | Для телефона |
| Сервер | Синхронізація між пристроями, Google Календар, підключення Claude | Ні — без нього все працює локально |

## Мови

Інтерфейс є українською та англійською. Мова перемикається в «Налаштування» → «Оформлення» → «Мова» і запам'ятовується окремо на кожному пристрої. Системні сповіщення й екран блокування на Android беруть мову з налаштувань самого телефона.

Ця документація — українською.
