# Встановлення і налаштування

Частини можна ставити в будь-якому порядку. Найпростіший початок — програма для ПК; сервер потрібен, лише якщо хочеш синхронізацію, календар чи Claude.

## 1. Програма для ПК (Windows)

Готова програма лежить у `dist\Focus\Focus.exe` у папці проєкту. Якщо її ще немає (наприклад, ти щойно склонував репозиторій), спершу збери її: у папці `desktop` виконай `npm install`, потім `npm run build` (потрібен Node.js).

1. Запусти `Focus.exe`. При першому запуску вона сама створює ярлики «Фокус» на робочому столі та в меню «Пуск».
2. Щоб програма стартувала разом із Windows: «Налаштування» → «Таймер і дані» → «Запускати разом із Windows». Вона запускатиметься одразу в трей.

Що варто знати:

- Закриття вікна ховає програму в трей. Повністю вийти — правою кнопкою на значку в треї → «Вийти».
- Без автозапуску нагадування і блокування працюють, лише поки ти запустив програму сам.
- Папку `dist\Focus` не переміщуй: на неї вказують ярлики й автозапуск. Якщо перемістив — запусти `Focus.exe` з нового місця (ярлик у «Пуску» оновиться), а автозапуск вимкни й увімкни знову.

### Оновлення після змін у коді

```bash
cd desktop
```

```bash
npm run build
```

Якщо програма в цей момент запущена, оновляться лише її внутрішні файли — перезапусти її через трей, щоб зміни застосувались. Якщо закрита, папка збирається заново повністю.

## 2. Розширення для браузера (Chrome, Edge)

Блокує сайти під час фокусу. Працює лише разом із запущеною програмою для ПК.

1. Відкрий `chrome://extensions` (в Edge — `edge://extensions`).
2. Увімкни «Режим розробника».
3. Натисни «Завантажити розпаковане розширення» і вибери папку `extension` у папці проєкту.

Папку `extension` не переміщуй і не видаляй — браузер читає розширення прямо з неї. Після змін у файлах розширення натисни кнопку оновлення на його картці.

## 3. Android

Файл для встановлення: `android\app\build\outputs\apk\debug\app-debug.apk` у папці проєкту. Він з'являється після збірки (див. «Збірка APK заново» нижче).

**Через USB (найнадійніше):** увімкни на телефоні «Налагодження USB» у параметрах розробника, підключи кабель і виконай:

```bash
"%LOCALAPPDATA%\Android\Sdk\platform-tools\adb.exe" install -r "android\app\build\outputs\apk\debug\app-debug.apk"
```

**Без кабелю:** перекинь файл на телефон і відкрий його; Android попросить дозволити встановлення з цього джерела.

Після встановлення:

1. При першому запуску дозволь сповіщення.
2. «Налаштування» → «Обрати програми» — познач, що блокувати.
3. «Налаштування» → «Увімкнути блокування» → у спеціальних можливостях увімкни «Фокус».

Якщо перемикач у кроці 3 сірий (Android 13+): «Налаштування» телефона → «Програми» → «Фокус» → меню ⋮ → «Дозволити обмежені налаштування», потім повтори.

### Телефони Xiaomi, POCO, Redmi

Прошивка HyperOS/MIUI агресивно зупиняє фонові програми. У «Про додаток» Фокуса:

- увімкни «Автозапуск»;
- «Економія заряду» → «Без обмежень».

Без цього служба блокування може вимкнутися сама, а нагадування — не прийти.

### Збірка APK заново

Відкрий папку `android` в Android Studio, або з командного рядка (потрібна Java 17+):

```bash
cd android
```

```bash
gradlew.bat assembleDebug
```

Збірка сама бере свіжий `index.html` з кореня проєкту.

## 4. Сервер (Linux з Docker)

Скопіюй на сервер файли `server/server.js`, `server/mcp-tools.js`, `index.html`, `Dockerfile`, `docker-compose.yml`, `.dockerignore`, `.env.example` зі збереженням структури папок.

1. Створи файл налаштувань:

```bash
cp .env.example .env
```

2. Згенеруй ключ доступу і впиши його в `.env` у рядок `FOCUS_TOKEN=`:

```bash
openssl rand -hex 24
```

3. Запусти:

```bash
docker compose up -d --build
```

Сервер доступний на порту 8090 (змінна `FOCUS_PORT` у `.env`; усередині контейнера — 8080); дані лежать у томі `focus-data`.

| Змінна | Значення | За замовчуванням |
|---|---|---|
| `FOCUS_TOKEN` | Ключ доступу, щонайменше 16 символів. Обов'язковий | — |
| `FOCUS_PORT` | Порт на хості, на якому доступний сервер | `8090` |
| `TZ` | Часовий пояс — від нього залежить, на який день потрапляють події календаря | `Europe/Kyiv` |
| `PORT` | Порт усередині контейнера | `8080` |
| `DATA_DIR` | Де зберігати базу | `/data` |

Сервер працює по HTTP без шифрування. Тримай його в домашній мережі або за VPN (наприклад, Tailscale) і не відкривай порт в інтернет.

Сервер також віддає сам додаток: з будь-якого пристрою в мережі відкрий `http://АДРЕСА-СЕРВЕРА:8090`.

### Підключення пристроїв

На кожному пристрої: «Налаштування» → «Синхронізація з сервером» → адреса (`http://192.168.x.x:8090`) і ключ із `.env` → «Зберегти і синхронізувати».

Якщо додаток відкритий прямо з сервера в браузері, адреса підставляється сама — лишається ввести ключ.

### Оновлення сервера

Скопіюй нові `server/server.js`, `server/mcp-tools.js` та `index.html` і виконай:

```bash
docker compose up -d --build
```

Дані в томі зберігаються.

## 5. Google Календар

1. У Google Календарі: «Налаштування» → вибери календар → «Інтеграція календаря» → скопіюй «Таємну адресу у форматі iCal».
2. У додатку: «Налаштування» → «Google Календар» → встав адресу → «Зберегти на сервері».

Адреса зберігається лише на сервері й ніколи не повертається пристроям. Порожнє поле вимикає календар. Ця адреса дає доступ на читання всього календаря — не діли її ні з ким.

## 6. Claude

Claude може вести твій план: додавати, змінювати й видаляти завдання та звички, розкладати їх по днях і часу, відмічати звички й показувати статистику. Підключається він до **програми для ПК** — сервер для цього не потрібен.

1. Запусти «Фокус» для ПК. У «Налаштування» → «Claude» є готова команда й готовий фрагмент налаштувань з уже підставленим шляхом.
2. **Claude Code:** виконай команду з налаштувань один раз. Вона має такий вигляд:

```bash
claude mcp add --scope user focus -- node "<папка проєкту>\dist\Focus\resources\app\mcp-stdio.js"
```

3. **Claude Desktop:** «Settings» → «Developer» → «Edit Config», додай фрагмент із налаштувань «Фокуса» у `claude_desktop_config.json` і перезапусти Claude.

Потрібен встановлений Node.js. Ключ доступу вводити не треба: програма зберігає його в `%APPDATA%\Focus\mcp-token`, а місток читає звідти сам. Якщо «Фокус» не запущений, місток запускає його в трей.

Після цього можна писати Claude звичайними словами:

- «Що в мене на цьому тижні?»
- «Додай на четвер о 10:00 здати лабу 4, перший крок придумай сам.»
- «Зроби звичку розминки щобудня о 8:00 після того, як прокинусь, мінімум — одна вправа.»
- «Відміть, що вчора я читав лише одну сторінку.»
- «Перенеси все, що не встиг сьогодні, на завтра.»

Claude знає правила «Фокуса»: пропонує час і крихітний перший крок, не перевантажує день і перед видаленням питає.

Зміни від Claude з'являються в програмі одразу і синхронізуються з телефоном, як звичайні.

### Через сервер

Сервер має такий самий набір інструментів за адресою `/mcp` — знадобиться, коли Claude працює на іншому комп'ютері в домашній мережі:

```bash
claude mcp add --transport http focus http://АДРЕСА-СЕРВЕРА:8090/mcp --header "Authorization: Bearer ТВІЙ_КЛЮЧ"
```

Поки сервер видно лише з домашньої мережі, підключити його до claude.ai в браузері чи на телефоні не вийде.

### Чого Claude не вміє

- Записувати події в сам Google Календар — він лише бачить їх, якщо календар підключено до сервера.
- Запускати й зупиняти таймер, змінювати налаштування та списки блокування.

## 7. Запуск без встановлення

`index.html` можна просто відкрити в браузері подвійним кліком. Працюватимуть план, таймер, статистика, теми й синхронізація; блокування — ні.

У згорнутій вкладці браузер сповільнює таймери, тож сигнал про кінець сесії може запізнитися до хвилини. У програмі для ПК цього немає.
